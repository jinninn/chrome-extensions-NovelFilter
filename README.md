# Novel Filter

カクヨム・小説家になろうの既読作品や非表示作品を一覧から除外するChrome拡張機能です。Manifest V3、ビルド不要、サーバー不要です。

本拡張機能は非公式です。各サイトの運営会社との提携・承認を示すものではありません。利用前に各サイトの利用規約をご確認ください。

[データの取り扱い](PRIVACY.md) / [公開・配布について](docs/publishing.md)

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、**このREADMEとmanifest.jsonがあるフォルダ**を指定します。
4. 既に開いているカクヨム・なろうのページを再読み込みします。
5. ツールバーの拡張機能アイコンからNovel Filterを固定すると便利です。

## 使い方

- ランキング・検索などの対応する作品カードに「既読にする」「非表示にする」が表示されます。
- 初期設定では本文を開くと作品単位で既読登録され、一覧から除外されます。全話読了の判定ではありません。
- 作品ページの左下にある「Novel Filter」を開くと、手動で登録・解除できます。
- 一覧の左下のメニューから「このページだけ再表示」を選ぶと、登録を変えずに一時的に確認できます。
- 拡張機能のポップアップで、自動既読（本文／作品ページ／手動）、非表示・半透明・置き換え表示を選べます。
- 「履歴・バックアップを管理」で、検索、状態変更、作品URLによる登録、JSON入出力ができます。
- 自動登録で「非表示」は上書きしません。同じページで手動解除した作品は、そのページを移動・再読み込みするまで再登録しません。

## 対応範囲と制限

カクヨム `kakuyomu.jp`、なろう `ncode.syosetu.com` / `yomou.syosetu.com` / `mypage.syosetu.com` のHTTPSページに対応します。成人向け別ドメインは含みません。ブラウザの過去の閲覧履歴は読み取りません。インストール後の閲覧・手動登録が対象です。

カードの識別はサイトのHTML構造に依存します。複数作品を含むコンテナや本文そのものは隠さず、判定できないカードはそのまま表示します。サイトの更新や一部ページでカードを認識できない場合は、管理画面のURL登録を利用できます。SPA遷移・追加読み込み・別タブの変更に追従します。

保存先は `chrome.storage.local` です。履歴を外部へ送信せず、解析ツール・広告・ログイン・中央サーバーはありません。容量はChromeの標準上限に従い、保存に失敗した場合はエラーを表示します。拡張機能を削除すると履歴も削除されるため、先にJSONを書き出してください。

## 互換データ

```json
{
  "formatVersion": 1,
  "works": {
    "narou:n1234ab": {
      "site": "narou",
      "workId": "n1234ab",
      "status": "read",
      "firstReadAt": 1789951000000,
      "updatedAt": 1789951000000
    }
  }
}
```

主キーは `site:workId`。IDは文字列、時刻はUNIXミリ秒です。`title` / `author` / `firstReadAt` は省略可能。`status` は `read` / `hidden` / `unread`。未読への変更も記録として残し、古いバックアップによる既読の復活を防ぎます。新しい更新日時を優先し、同時刻の競合は正規化したレコードのJSON文字列比較で統一します。設定はエクスポートしません。

取り込みは全件検証後にマージします。未知の形式バージョン・状態はエラーにし、黙って捨てません。10MB・10万件までを受け付けますが、実際の保存可能量はChromeのストレージ上限に依存します。書き込みはサービスワーカーで直列化しています。

Safari Userscript、自動同期、QR、WebDAVは将来の拡張対象で、この版には含まれません。コアのデータ処理とサイト判定はChrome APIから分離しています。

## 開発・検証

Node.js 20以降で `npm.cmd ci`、`npm.cmd test`、`npm.cmd run check` を実行します（PowerShellの実行ポリシーによっては `npm` の代わりに `npm.cmd` を使ってください）。開発テストにのみlinkedomを使用します。拡張機能を利用するだけなら依存ライブラリのインストールやビルドは不要です。

- `src/core.js`: 共通データ形式、URL判定、マージ
- `src/sites.js`: サイトの作品カード・本文判定
- `src/background.js`: 保存と更新の直列化
- `src/content.js`: ページ内操作・非表示処理
- `popup.html` / `options.html`: 設定と履歴管理

手動確認: 両サイトで作品を既読登録 → 一覧に戻って除外 → 一時再表示 → 未読へ戻す。短編本文・連載目次・各話本文も確認してください。2タブで登録し、バックアップ書き出し・取り込み・古いバックアップのマージ後に未読への変更が維持されることを確認できます。
