# 公開・配布について

## リポジトリ

公開用のソースと、架空の入力を使用する自動テストを収録しています。テスト用の名前・IDは検証用の例であり、特定の利用者の読書履歴を表すものではありません。実際の履歴、取得したサイトHTML、認証情報はコミットしないでください。

`.gitignore` はGitで未追跡のファイルを除外する設定です。追跡済みのファイルや過去のコミットは消去しません。また、フォルダをそのまま圧縮・アップロードする操作には適用されません。

作業フォルダの `.git` には過去のファイル、コミット情報、接続設定などが含まれます。`.git` や `node_modules`、ローカルの設定・バックアップを含む作業フォルダ全体は配布せず、配布スクリプトが生成したZIPを使用してください。

## 拡張機能の配布ファイル

PowerShellから次のコマンドを実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

`dist` に、指定した実行用ファイルと説明文書のみを含むZIPを作成します。テスト、開発用依存ライブラリ、Git履歴、個人用バックアップは含めません。ZIPを展開したフォルダをChromeへ読み込めます。
