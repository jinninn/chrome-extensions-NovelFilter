# 初期版の仕様

初期版の対象とデータ設計をまとめています。

- 名前: Novel Filter
- 初期対象: PCのChrome拡張。カクヨム・小説家になろう。
- 既読作品・手動で非表示にした作品を一覧から除外。
- 運営用のサーバーやアカウント登録を必須にしない。
- iPhoneのSafari UserscriptはChrome版完成後に検討。
- 保存形式はブラウザ非依存のJSON。`formatVersion`、`site`、文字列の`workId`、`status`、`updatedAt`を使用。
- JSON入出力を備え、取り込み時は更新日時の新しい方を優先してマージ。
- サイトの判定、ID抽出、データ管理、表示制御、Chromeの保存処理を分離。

初期版で追加した具体的な動作:

- 自動既読は「本文を開いたら」を初期値にし、作品ページ・手動のみも選択可能。
- 非表示・半透明・プレースホルダー表示を選択可能。
- 未読に戻した変更を履歴に残し、古いバックアップで既読が復活するのを防止。
- 本文自体や複数作品を含むコンテナはフィルター対象外。
- 自動登録は非表示の登録を上書きしない。
- 履歴の検索、手動URL登録、状態変更を管理画面で提供。

QR・WebDAV・Gist同期、iPhone版は実装範囲外です。
